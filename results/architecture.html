User surface Validated OOS ✓ Honest caveat △ Interpretable link
Design law. (1) No shared trainable backbone — modules never share weights one task's gradient can corrupt, so one module's training can never degrade another's. (2) Interpretable links only — modules connect through a glass-box combiner, an inspectable connectedness graph, and a named regime state; every link is a number you can point at. (3) Every claim is gated by an OOS test and an adversarial null — a module earns its place only if it beats a baseline out-of-sample and survives a test built to kill it.
