01What it is & the design law

Meridian is not one model. It is a bank of decoupled, individually-interpretable specialist modules, each benchmarked out-of-sample, linked by objects a human can read and audit. This design was proven, not assumed: a single model that tried to generalize across tasks degraded (collapsing the regime module into the vol backbone, or starving a decoupled module); only decoupled modules — each with its own objective, linked by interpretable combiners — kept every win.

The design law — "link without degradation"
1. No shared trainable backbone. Modules never share weights one task's gradient can corrupt — so one module's training can never degrade another's.
2. Interpretable links only. Modules connect through a glass-box combiner, an inspectable connectedness graph, and a named regime state — every link is a number you can point at and explain. No opaque cross-attention.

A third law emerged from this session's audits: every claim is gated by an OOS test and an adversarial null. A module earns its place only when it beats a baseline out-of-sample and survives a test designed to kill it. When the evidence contradicted a claim, the claim was corrected — including our own.

Data flows up into causal measures, fans out to the decoupled module bank, and is recombined by an interpretable glass-box combiner. The interactive engine answers any user query; the conversational contract guarantees every emitted number came from a module.

03Data & measurement layer

All data is free / delayed and fetched live on every query (so the model is always current — the practical form of "continual"). The entity resolver maps any natural-language name or ticker to a market symbol via Yahoo's global search — verified on US equities, global equities (e.g. RELIANCE.NS), FX, crypto, futures and indices. Unknown / private entities trigger an honest "share a source" request rather than a fabricated answer.

  • Realized variance — Garman-Klass OHLC estimator (robust, no intraday feed needed).
  • HAR cascade — daily / weekly / monthly components (Corsi 2009) plus a leverage / bad-vol term (variance from down-moves).
  • Data-quality guard — RV winsorization + a trailing-year forecast cap; continuous-futures roll-gaps are flagged (warn, don't emit garbage), and commodity aliases route to clean ETFs.

05Interpretability standard

"Interpretable from foundations" is a testable claim, so it has a bar (ascending strength), and every module is audited against it:

  1. Faithfulness (minimum) — the output must provably change when the explanation changes. Attention weights, gate activations, and post-hoc SHAP/LIME are decorative until proven faithful; they are never presented as "why".
  2. Causal necessity (ablation) — removing a module must move the forecast in the pre-registered direction.
  3. Causal sufficiency (clamp), bounded & OOS-tested — forcing a state reproduces the target behavior, validated out-of-sample.

Attributions that get shipped must survive the Adebayo randomization sanity check (shuffle labels / randomize the sub-model → the attribution must move) and, for weight-like importances, beat a uniform-weight and multi-seed-variance baseline. Faithfulness is treated as graded, not binary (Jacovi-Goldberg).

Two headline results were corrected downward this cycle by adversarial tests: the network's stress connectedness is interdependence, not contagion (Forbes-Rigobon); and hidden volatility regimes are marginal, not strong, once the null properly embeds HAR heteroskedasticity. Both corrections are recorded, not buried — that is the point.

07The interactive engine

A user asks in plain language; the engine resolves the entity, fetches live data, runs the module bank, and explains. Five modes:

ModeWhat it answers

compareSide-by-side risk of two entities
scenario"What-if a market move" via single-beta propagation
worldMulti-entity shock propagation through the validated generalized-IRF network

An interactive dashboard renders these over a live snapshot (entity cards, comparison, a scenario slider driving the network, portfolio optimization) — a companion to this document.

08Conversational contract

The interactive layer follows a strict division of labor: the LLM routes and explains; the calibrated modules own every number. A provenance ledger logs each emitted figure to its module call, and a verifier checks that no number in an explanation is un-traced. In testing, an honest paraphrase passes and a deliberately-invented figure is caught — hallucinated numbers are made architecturally impossible, not merely discouraged. The LLM may never present gate/attention weights as "why"; only ablation-verified attributions are surfaced.

09Research program & discipline

The roadmap is driven by adversarially-verified deep research — each pass fans out web searches, fact-checks every claim with independent skeptics, and synthesizes a ranked plan. Passes this program: JEPA/world-model variants; generative-latent methods; realized-measure decomposition; the interactive/any-entity architecture; higher-order implications & event simulation; world-model + interpretability + financial-theory foundations; and a frontier pass on dynamic connectedness, regime rigor, interpretability, covariance/tail, and novel synthesis.

What we refuse to build (evidence says it produces confident nonsense)
Causal-discovery / DAG layers (weak-instrument-fragile artifacts) · GAN/diffusion scenario generators (catastrophic backtests) · deeper per-series neural vol nets (HAR is hard to beat) · an energy/JEPA regime engine (displaces a working interpretable module) · routing the EVT tail through an isotropic-Gaussian latent (thin tails destroy tail structure) · Cholesky-HAR covariance (order-dependent) · any "contagion" claim (the FR gate stands) · long-horizon point-IRF extrapolation (variance-dominated).

10Honest boundaries — what we can & cannot claim

CAN claim: conditional volatility levels & term structure; tail VaR/ES with backtested coverage; variance connectedness & shock propagation (co-movement, OOS-validated); covariance-based min-variance portfolios; which variance regime we are in, as a pre-registered convention.

CANNOT claim: the direction or level of future returns; that better volatility forecasting equals large trading alpha (it does not on daily data — settled across many experiments); that any latent coordinate "is" a named factor without an identifiability test; a "discovered" (vs imposed) crisis regime; HAR beyond the ~22-day cascade (it mis-extrapolates — Corsi's own flag); any attribution not verified by ablation; personalized investment advice.

This is a measurement-and-forecast system, best-in-class where measured — not an oracle. In a market that distrusts black boxes, that honesty is itself a feature.

11Roadmap

Ranked, each gated by an OOS test + an adversarial null:

  1. Order-invariant realized covariance — matrix-log-HAR (refuse Cholesky); adversarial null = asset-ordering permutation test.
  2. Honest multi-horizon bands — lag-augmented local projections with an explicit "honest-horizon" cutoff beyond which bands are disclosed as not-guaranteed.
  3. Second wave — TVP-VAR + frequency-domain connectedness (short vs long-run spillovers), FR-gated; and the one genuinely novel mechanism: a TDRL identifiable regime latent (VAE + flow prior, vol-percentile / EPU as the observed auxiliary variable) with provable recovery up to permutation — resolving the state-space non-identifiability that retired the old switching module.
